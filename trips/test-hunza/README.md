# test-hunza: test day assembled from internet photos

Karimabad to Passu along the Karakoram Highway, Hunza, Gilgit-Baltistan.

**Test data, not a hike.** The photos are real and so are the camera positions (from each file page), written into the EXIF. The clock times are invented to put the stops in route order on one day, and the voice notes were written to describe each photo and read by a speech engine. Built by `tools/make_internet_days.py`.
