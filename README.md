# Lake Lookout

Hike with your phone. Take a photo at each lake and say what you see.
That evening, with no internet, a local open-weight model (Gemma 4 via Ollama)
turns the day into a glacial-lake field log: a checklist per stop with the
evidence for every answer, a CSV/GeoJSON file a researcher can use, and one
offline page with your route and photos.

Work in progress for the DEV Hacktoberfest 2026 Open-Source AI Challenge
(Week 1, "Touch Grass").
